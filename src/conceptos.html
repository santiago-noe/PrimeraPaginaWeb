Componentes

Los componentes son las partes principales que forman un sistema de software. Cada componente tiene una responsabilidad específica, por ejemplo: gestionar usuarios, procesar pagos o enviar notificaciones.

Capas

Las capas permiten organizar el sistema según diferentes responsabilidades. Una aplicación típica tiene tres:

Las tres capas de una aplicación
Capa Responsabilidad Ejemplo
Presentación Mostrar información y recibir acciones del usuario. Páginas web, pantallas de una app.
Lógica de negocio Aplicar las reglas del sistema. Calcular el total de una compra.
Datos Guardar y recuperar información. Base de datos MySQL o PostgreSQL.

Interfaces

Las interfaces establecen una forma de comunicación entre componentes o sistemas. Un ejemplo muy común es una API que responde a peticiones como esta: 

GET /api/usuarios/15
Respuesta: { "id": 15, "nombre": "Ana" }

Glosario

Acoplamiento
Grado de dependencia entre dos componentes. Lo ideal es que sea bajo.
Cohesión
Qué tan relacionadas están las tareas dentro de un mismo componente. Lo ideal es que sea alta.
Escalabilidad
Capacidad del sistema para crecer y atender a más usuarios.
